# LarocheConstruction.md

# PROMPT MAÎTRE — LAROCHE CONSTRUCTION
## Création complète d'une plateforme web BTP moderne, premium, interactive et commerciale

---

## 0. MISSION

Concevoir et développer un site web complet, moderne, premium et professionnel pour **Laroche Construction**, une entreprise de BTP / construction.

Le site ne doit surtout pas ressembler à un simple site vitrine générique d'entreprise de construction.

Il doit donner l'impression d'une **entreprise de construction ambitieuse, fiable, moderne et technologiquement avancée**, tout en servant de véritable plateforme commerciale.

Le site doit permettre :

- de présenter Laroche Construction ;
- de présenter ses services ;
- de présenter ses méthodes de travail ;
- de montrer ses réalisations sous forme de vidéos ;
- de publier automatiquement les nouvelles vidéos depuis YouTube ;
- de publier des actualités et événements ;
- de permettre à un client de concevoir virtuellement son projet de maison ;
- de calculer une estimation budgétaire en FCFA ;
- de demander un rendez-vous avec le promoteur ;
- de rechercher des plans de maisons professionnels ;
- de prévisualiser les plans PDF avant achat ;
- de vendre les plans en ligne ;
- de délivrer automatiquement les plans après paiement ;
- de communiquer avec les clients par WhatsApp et email ;
- de notifier l'équipe Laroche par Telegram ;
- de fournir un tableau de bord administrateur complet ;
- d'être fortement optimisé pour Google et les moteurs de recherche utilisant l'IA.

Le résultat doit être **responsive, rapide, accessible, sécurisé, SEO-first et très visuel**.

# 31. PDF PREVIEW

Le client doit pouvoir consulter le contenu du plan avant achat.

Le PDF original doit rester privé.

Architecture :

PUBLIC PREVIEW
→ aperçu contrôlé / watermarké

ORIGINAL PDF
→ stockage privé

Après paiement :
→ accès sécurisé.

La plateforme ne peut pas garantir l'impossibilité absolue de capture d'écran.

Mettre en place des mesures de protection :

- watermark ;
- preview basse / moyenne résolution lorsque pertinent ;
- suppression du téléchargement depuis le preview ;
- stockage privé ;
- URLs signées temporaires ;
- accès serveur contrôlé.

Le PDF haute qualité n'est jamais exposé publiquement par une URL permanente.
