CONFIGURATION SERVEUR

Connexions API

Ne saisissez aucun secret ici.

Configurez les secrets dans les variables d’environnement Vercel : SUPABASE_URL, SUPABASE_PUBLISHABLE_KEY, SUPABASE_SECRET_KEY, ADMIN_SESSION_SECRET, MONETBIL_SERVICE_KEY, MONETBIL_SECRET_KEY, MONETBIL_NOTIFY_URL, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, GOOGLE_APPS_SCRIPT_URL, GOOGLE_APPS_SCRIPT_TOKEN, YOUTUBE_API_KEY et YOUTUBE_CHANNEL_ID.

Monetbil : paiement et callback signé. Google Apps Script : envoi du PDF après paiement confirmé. Telegram : demandes et notifications. YouTube : lecture serveur, clé jamais transmise au navigateur.

Le programme Visual Basic .exe est distinct du site Vercel; il ne doit pas intégrer de clé serveur et devra utiliser les mêmes API protégées.
